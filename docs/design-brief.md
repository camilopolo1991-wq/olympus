# Design brief: Olympus, first build

Build Olympus, a local pixel-art dashboard that shows an AI team at work, as a static web page opened from one command. Work in this repository only, on a branch, never on main. Read-only everywhere else. Never read any file named .env, config.env, names.txt, auth.json, any state.db, anything under sessions, logs or cache. Never print a person's name; the only names are the seat titles THE CHAIR, THE FORGE MASTER, THE MESSENGER, THE TIDE, THE KEEPER and the five roles leader, scout, writer, reviewer, auditor. Read README.md, docs/feed-contract.md and CREDITS.md first; the contract is binding.

STUDY FIRST, patterns only, copy no code: the agent-town repository by rafapetter on GitHub (status vocabulary; how a log drives character state) and the pixel-agents repository by pixel-agents-hq on GitHub (office layout, sub-agents as extra characters, provider interface); both are MIT, find them by name. Write ten lines of what you took from each into docs/notes-first-build.md.

ENGINE: Phaser 4 from cdnjs, pixelArt true, zoom 3, Tiled JSON tilemaps, plain HTML and CSS panels beside the canvas. No build step, no framework, no bundler: index.html, app.js, map.json, assets/, server.py, sample.log, tests/.

ART, download only the packs CREDITS.md clears, and add one CREDITS line per file used. If a download fails, draw a 16 px placeholder tile in the palette and say so. Draw by hand, 16 px each: an anvil, a chimney with three smoke frames, a notice board lit and unlit, a cyan lightning bolt. Palette: ground #07080c, panels #1b1f27, gold #e3b341, amber #ff8a3d, cyan #35d6ff, text #e9e4d6. Night map, neon gold and cyan outlines on dark stone, Greek key pattern as 1 px borders. Everything pixel art, the panels included: 1 px gold bevels, no gradients, no shadows, no emoji. Fonts from Google Fonts: Press Start 2P for titles, VT323 for panels, a monospace for the log.

MAP (Tiled JSON, 16 px, 60 by 34 tiles): sea; two islands joined by a pier. OLYMPUS: a crag with clouds and three temples, THE CHAIR lit with the bolt above it, THE TIDE and THE KEEPER unlit with a "not built" label; THE MESSENGER on the pier, dim. THE FORGE island: a smithy with the anvil and smoke, five huts (roof in the role colour: leader gold, scout blue, writer green, reviewer violet, auditor red), a RECORD house with a gold-lit door, the notice board labelled WINDOW. Leave dim coastline for two future domains.

FEED: server.py exactly as docs/feed-contract.md section 3 says, Python standard library only, port 8765. sample.log: sixty lines in the grammar with made-up goal KIT-06 and tasks T01 to T08, including one planted 40-hex token and one planted 5-segment path for the masking test.

STATE MACHINE in app.js, as the contract's kind table says: a role figure leaves its hut on DISPATCH for its site (writer to the anvil, scout, reviewer and auditor to the record house, leader to the board) and returns on a returning kind for the same step; the anvil glows while a writer works; the board glows cyan while a window is open; INCIDENT flashes the frame red once; HELD dims the map and shows a gold banner "Gate waits for you"; DONE lights the record house; COMMIT or PUSH stamps the record house for two seconds. Panels: goal id and status, window, counters by line kind with the kind named under each number, a task table (task, last word, retries), a ticker of the last 40 lines, play, pause, speed and a scrub bar for replay.

ACCEPTANCE, tests/ holds one script that checks each and prints PASS or FAIL per row: the server serves the page from the one command; every figure starts home; after replay every task in sample.log shows its last word; the planted token is served with 8 characters; the planted path with 2 segments; a truncated log resets the offset; CREDITS.md lists every file under assets/; no console errors (print the browser console if you can run one, else say you could not). Commit on a branch named first-build with a Conventional subject; do not push; do not touch main. Then update README.md if anything above changed, and describe exactly what is on screen at the start and at the end of the replay, with screenshots if you can take them.
